### 📚 Weekly Study Materials

All **SOFT2412 weekly materials** in this repository were collected directly from the official **Ed Discussion** course platform.

You can simply upload these weekly documents to an AI tool (such as ChatGPT or Claude) and ask it to summarise the key concepts.

The AI can help you:
- Extract important concepts and definitions.
- Explain difficult topics with examples.
- Organise the content into structured revision notes.
- Generate practice questions for self-assessment.

**Suggested prompt:**
```text
Summarise all key concepts from these SOFT2412 weekly materials. Organise the content by topic, explain important definitions, include examples, and ensure no examinable concepts are omitted.
```

**Note:** These materials are sourced from Ed Discussion. AI-generated summaries should be cross-checked against the original documents for accuracy and completeness.
